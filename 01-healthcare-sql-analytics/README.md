## 1. Project Overview

This project focuses on developing a SQL-based data quality validation system for a fictional healthcare organization.

The solution aims to identify inconsistencies in beneficiary records, healthcare coverage, providers, medical claims and payments.

## 2. Business Problem

Healthcare organizations depend on accurate data to maintain reliable operational and financial processes.

Data inconsistencies can lead to duplicate records, invalid coverage, incorrect claims and unreliable reports.

## 3. Project Objectives

- Identify duplicate beneficiary records.
- Detect incomplete registration data.
- Validate healthcare coverage periods.
- Identify duplicate medical claims.
- Analyze payment inconsistencies.
- Generate data quality indicators.

## 4. Database Structure

The database will contain five main tables:

- Members
- Providers
- Coverage
- Claims
- Payments

## 5. Technologies

- PostgreSQL
- SQL
- Relational Database Modeling
- Data Quality Validation
- Healthcare Analytics

## 6. Project Deliverables

- Database schema
- Synthetic datasets
- SQL validation queries
- Data quality reports
- Technical documentation
- Project findings and recommendations

## 7. Data Privacy

All information used in this project is fictional and generated for educational and professional demonstration purposes.

No real patient, beneficiary or provider information is used.

## Qualidade de Dados e Análise em Saúde

Desenvolvimento de um sistema de validação de dados utilizando SQL, aplicado a uma operadora de saúde fictícia.

O projeto tem como objetivo identificar inconsistências em cadastros, coberturas, prestadores, contas médicas e pagamentos.
